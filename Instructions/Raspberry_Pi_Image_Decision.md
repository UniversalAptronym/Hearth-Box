Chose which imaging software you are going to use to install your Pi. This software lets you use your computer to install other software onto your equipment. 
DEVELOPER NOTE: (Pre-made) is aspirational, for now we're just putting together the resources for (Manual)

([Manual](../Instructions/Raspberry_Pi_Image_Setup.md)) There is a list of tools and instructions with which you can install a fresh Raspberry Pi OS and add everything you need.

(Pre-made) The goal for this is to make prepared images (copies of everything needed to make your Pi a computer with software) and scripts (small programs which will ask you for your inputs) which will let you set everything up with as little input as possible. You will only need to type in things like your wifi name and password, your desired usernames and passwords, your domain name, etc.
